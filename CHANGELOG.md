# Changelog

All notable changes to GMOnt are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - Unreleased

### Added
- Domain-general model for persistent entities, archival records and media objects.
- Longitudinal record links through `previousRecord`, `nextRecord`, `relatedRecord` and `sameSubjectAs`.
- Generations/cohorts/lifecycle stages through the `Generation` pattern.
- Human/family specialization for kinship and memory records.
- SHACL integrity constraints.
- Human/family-memory and building-lifecycle examples.
- Executable SPARQL query catalogue.
- Automated RDF, SHACL and SPARQL validation.

### Changed
- Canonical namespace aligned with the final repository name.
- Core ontology standardized as `GMOnt.ttl`.
- Examples, shapes and queries organized into dedicated directories.
- Citation and archival metadata aligned with the final repository URL.
